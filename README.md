I am a **Full-Stack Developer & Security Engineer** building resilient web applications with a security-first architecture, then auditing and testing them the way an attacker would.

## 🚀 Featured Projects

### ⬡ [Vertex Canvas](https://github.com/DevTechMike-Coder/KanbanTool)
> **Full-Stack Workspace with Defensive Architecture**

A real-time workspace with Kanban boards, notifications, team management, and file storage—engineered with zero-trust application boundaries.

* **Security Controls:**
  * **Auth & Sessions:** OAuth 2.0 with PKCE and HMAC-SHA256 signed session cookies.
  * **Authorization:** Server-side access verification protecting against IDOR / Broken Object Level Access (BOLA).
  * **Hardened File Pipelines:** Magic-byte validation, distributed rate limiting, and dynamic Content Security Policy (CSP) headers.
* **Tech Keywords:** `nextjs` `typescript` `react` `postgresql` `prisma` `supabase` `tailwindcss` `rbac` `security`
